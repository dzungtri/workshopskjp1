# AI生成PRのレビューチェックリスト (人間用)

> 「テストが green」= 「正しい」ではない。AIのPRは**自信満々に見える**ので、以下を必ず確認する。

## 1. スコープ
- [ ] チケットの「変更してよいファイル」だけが変更されているか (`git diff --name-only main`)
- [ ] 頼んでいないリファクタ・ついでの変更が混ざっていないか

## 2. テスト
- [ ] 既存テストが削除・skip・期待値変更されていないか (`git diff main -- test/`)
- [ ] `test/golden/*.json` が変更されていないか
- [ ] 新しい挙動に対するテストがあるか。**失敗するケース・境界値**のテストがあるか
- [ ] テストが実装をなぞっているだけ (同じ式で期待値を計算) になっていないか

## 3. 業務ルール
- [ ] `docs/business-rules.md` の「決定者: 人間」のルールと一致しているか
- [ ] TBD のルールを勝手に決めて実装していないか
- [ ] 金額は整数円か。端数処理 (切り捨て/切り上げ) の位置は正しいか

## 4. お金・状態まわり (重点)
- [ ] 二重実行 (リトライ・二重クリック) で二重課金・二重返金にならないか
- [ ] 失敗時に状態・在庫・金額が中途半端に残らないか
- [ ] 時刻は `clock()` 経由か。タイムゾーン・境界 (ちょうど8日) は正しいか

## 5. 最後に
- [ ] 自分の言葉で「この変更が何をするか」を説明できるか。できなければマージしない
