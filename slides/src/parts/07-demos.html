DEMO ① 6分 · 操作: ./demo/go.sh 1 → ⌘V → Enter 待ち時間: 画面の tool call を指さして説明
では、実際に動かしてみます。 ここに、「返品期限を過ぎても返金されてしまう」というバグがあるブランチがあります。 エージェントにお願いするのは、この一文だけです。 （コピペして実行 · 試したときは約40秒） 見てください。まず git の履歴とファイルを読んでいます。Read です。 次に、テストを実行して、バグを再現しています。Bash です。1件失敗しました。 そして、境界のテスト「8日と1秒は拒否」を先に追加してから、コードを直しています。 最後に、全部のテストと lint を実行しました。 テストが全部通って、tool_use がなくなったので、終わりました。 今のが Agent Loop です。次のスライドで、中で何が起きていたかを見ます。
VN thao tác: (1) cd workshop/ec-demo; ./demo/go.sh 1 (tự reset + copy prompt + mở claude) (2) ⌘V Enter (3) trong lúc chạy, chỉ vào Read/Edit/Bash, test fail → tự sửa (4) nếu chạy lâu: vừa chờ vừa giải thích tool call trên màn hình. Lưu ý: Stop hook sẽ tự chạy npm test khi agent định kết thúc.
