「テストやレビューの工数こうすうを減へらしたい」というご質問しつもんもありました。5つ紹介しょうかいします。

【→】1つ目め。PRを小ちいさくする。200行を5本の方かたが、1,000行を1本より、ずっと速はやくレビューできます。

【→】2つ目め。テストを先さきに書かかせて、人ひとはテストをレビューする。テストは実装じっそうより短みじかくて、意図いとが読よみやすいです。テストが正ただしければ、実装じっそうはAIに任まかせられます。

【→】3つ目め。Golden test。人ひとが手てで計算けいさんして承認しょうにんした期待きたい値ちの表おもてです。右みぎがその例れいです。返金へんきん額がく371円。これはAIに変更へんこうさせません。

【→】4つ目め。Mutation testing。わざとコードを壊こわして、テストが赤あかくなるかを見みます。テストのテストです。
例たとえば、「<=」を「<」に変かえてもテストが緑みどりなら、そのテストは境界きょうかいを見みていません。

【→】5つ目め。AIに一いち次じレビューをさせて、人ひとは要点ようてんだけ見みる。
PRの説明せつめいに、「判断はんだんしたこと」「迷まよったこと」を書かかせると、人ひとは迷まよった所ところだけ見みればいいです。


VN: Giảm công: PR nhỏ; test trước, người review TEST; golden test (expected do người duyệt, AI cấm sửa); mutation testing = test của test (đổi <= thành < mà test vẫn xanh → test không kiểm biên); AI review vòng 1 + PR ghi "đã quyết gì, phân vân gì".
